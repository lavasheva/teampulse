# Расчёт вклада TeamPulse

Периоды выражаются в UTC. Начало включается, конец исключается. Неделя начинается в понедельник. Дата окончания проекта включается целиком. `asOf` при необходимости ограничивает период для текущего отчёта. Итоговый расчёт получает события за весь проект и применяет те же правила к накопленным баллам.

| Категория | Баллы до применения весов |
| --- | --- |
| Код | 1 балл за 20 допустимых изменённых строк (вставки + удаления), максимум 500 строк на коммит. Если есть только пути допустимых файлов, начальная оценка 0,25 балла за коммит. |
| PR | 1 за открытие, ещё 2 за слияние, 0 за закрытие без слияния. Вся жизнь принятого PR даёт 3 балла. Слияние в другой неделе даёт только прибавку. |
| Ревью | 1 за представленное ревью, 2 при наличии текста или запросе изменений. Dismissed и pending дают 0. |
| Issues | 0,5 за создание и 1 за закрытие, авторы действий берутся из событий. Текущее назначение задачи не доказывает, кто её выполнил. |

В PR учитывается работа по представлению и доведению изменений до принятия. Объём строк начисляется только по коммитам. Доставка одного события несколько раз не меняет результат. Дополнительная дедупликация использует GitHub URL объекта и вид действия. Для закрытий issues учитывается также UTC-дата: несколько закрытий задачи за день дают один сигнал закрытия.

Поле `work` хранит баллы до применения весов. Общий балл равен сумме произведений баллов категорий на веса, делённые на 100. Доля равна 100 × балл участника / балл команды. Доли категорий рассчитываются от суммы исходных баллов категории. При нулевом знаменателе доля равна нулю. События без сопоставленного участника остаются в отчёте отдельно и не входят в сумму баллов.

Активный день — день с действием, которое получило исходные баллы. Нулевой вес категории не отменяет активный день. Регулярность выражается долей активных календарных дней периода и средним интервалом в днях между активными датами. Для менее чем двух дат интервал отсутствует. Джини нормирован для конечной команды: для отсортированных баллов `x` это `Σ((2i−n−1)×xᵢ) / ((n−1)×Σxᵢ)`, где `i` начинается с 1. Если сумма равна нулю или участников меньше двух, Джини равен нулю.

## Примеры

1. 40 строк дают 2 балла кода. Вместе с открытым и принятым PR это 2 балла кода и 3 балла PR. При весах 50/20/20/10 общий балл равен 1,6.
2. При общих баллах 3, 1 и 0 доли составляют 75%, 25% и 0%, Джини равен 0,75.
3. В первую неделю команда получила 1 балл, целиком от А. Во вторую Б получил 9 баллов. Итоговая доля А составляет 10%.
