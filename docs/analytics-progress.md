# Аналитика TeamPulse

- Реализованы недельный и итоговый расчёт, регулярность, Джини, дедупликация, корректировки кода, шесть флагов и русскоязычная сводка.
- Пройдено 19 тестов аналитики, в том числе HTTP-моки для YandexGPT и GigaChat. [Формулы и подключение](analytics.md).
- Ограничения — эвристики по путям и объёмам, предварительные баллы без статистики по файлам, ограниченная история недельного снимка. Провайдеры проверены с моками.
- Следующий шаг — закончить общие проверки и подготовить PR. Подключение воркера и публичного API остаётся у бэкенда.
