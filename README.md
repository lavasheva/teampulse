# TeamPulse

TeamPulse показывает активность команд в GitHub и помогает руководителям и участникам видеть вклад в командный проект. Веб-клиент MVP работает на локальных демо-данных.

## Локальный запуск

Нужны Node.js 24 и pnpm 10.17.1. При использовании nvm запусти `nvm use` в корне проекта.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Vite напечатает адрес, обычно это `http://localhost:5173`.

## Демо

- Кнопка «Войти через GitHub» на главной открывает профиль преподавателя. В нём доступны список проектов, создание проекта с первой командой, обзор, сводки и настройки.
- «Перейти по ссылке» на экране входа открывает приглашение в демо-проект. Через приглашение можно войти как студент и выбрать команду. Участник видит только свою команду и может подтвердить авторство неопознанного коммита.
- В «Кодзилле» есть данные для графика, лента событий, флаги и итоговый отчёт. Кнопка «Сохранить как PDF» открывает печать браузера.
- Роль, созданные проекты и настройки сохраняются в хранилище сайта в текущем браузере. Приглашение в созданный демо-проект открывай в том же профиле браузера. Для сброса демо очисти данные сайта.

Вход, события, сводки и рассылка моделируются в браузере. Подключение репозитория отложено. В примере «Кодзиллы» уже есть репозиторий и синтетические события. Изменение весов, порогов и подтверждение автора сохраняются в демо, расчёт вкладов остаётся частью будущей интеграции с аналитикой.

## Проверки

```sh
pnpm lint
pnpm build
pnpm test
pnpm --filter @teampulse/web exec playwright install chromium
pnpm test:e2e
```

Клиент находится в `apps/web`. Общие черновые типы для интеграции находятся в `packages/shared`. Запросы идут через TanStack Query, данные выдаёт локальный адаптер из `apps/web/src/data`.
