# Аналитика TeamPulse

- Реализованы недельный и итоговый расчёт, регулярность, Джини, дедупликация, корректировки кода, шесть флагов и русскоязычная сводка.
- На Node.js 24 прошли сборка, линтинг, проверка типов и 65 тестов монорепозитория, из них 19 тестов аналитики. Проверен импорт собранного пакета.
- В [CI PR №24](https://github.com/lavasheva/teampulse/actions/runs/44613818331) прошли основные проверки и развёртывание с тестовым восстановлением PostgreSQL. HTTP-адаптеры YandexGPT и GigaChat проверены моками.
- Проверены границы флагов и сценарий с тишиной участника, перекосом вклада и высокой долей исключённых строк. Для тишины воркер должен передавать фактически покрытый период.
- [Формулы, ограничения и подключение](analytics.md). Следующий шаг для бэкенда — вызвать движок из обработчика пересчёта и передать результат через API.
